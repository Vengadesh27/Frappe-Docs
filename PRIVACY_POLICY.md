# Privacy Policy

**Frappe Docs**
Last updated: June 20, 2026

---

## 1. Overview

Frappe Docs is a self-hosted application. This Privacy Policy explains how data is handled when you use the App within your own Frappe environment.

## 2. Data We Do Not Collect

Makeown (the developer of Frappe Docs) does **not** collect, store, or have access to any of the following:

- Document content you create or edit
- User accounts or credentials
- Comments or sharing configurations
- Any personally identifiable information entered into the App

All data remains exclusively on your own server or Frappe Cloud instance.

## 3. Data Stored on Your Instance

The following data is stored in **your own** Frappe database:

| Data | Purpose |
|---|---|
| Document title and content | Core document storage |
| Permission mode | Controls who can view/edit the document |
| Comments (JSON) | Threaded comment threads per document |
| Shared users (JSON) | Per-document access control list |
| Frappe User records | Created and managed by Frappe Framework |

## 4. Third-Party Services

Frappe Docs does not make any calls to third-party services or external APIs. No analytics, tracking, or telemetry is included.

> **Note:** If your Frappe instance is hosted on Frappe Cloud, Frappe's own privacy policy governs infrastructure-level data handling.

## 5. Data Security

Security of your data depends on your server configuration. We recommend:

- Using HTTPS for all traffic
- Setting strong passwords for all Frappe users
- Keeping Frappe Framework and Frappe Docs updated

## 6. Data Deletion

Documents can be deleted by their owner at any time from within the App. User accounts can be removed by your Frappe Administrator.

## 7. Children's Privacy

The App is not directed at children under 13. If you are a Frappe Administrator, ensure your users comply with applicable age requirements.

## 8. Changes to This Policy

We may update this Privacy Policy from time to time. The "Last updated" date at the top will reflect any changes.
